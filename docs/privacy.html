Privacy policy

Second · last updated 12 September 2026

Second is a demonstration project built for a hackathon. It runs against a single developer's own Google account. There is no sign-up and it is not accepting users. This policy describes what the software does with data when it runs.

What Second accesses

With your consent, through Google OAuth, Second requests:

  • calendar — read your calendar and create or move events.
  • gmail.readonly — read your mail, to find evidence that explains why planned work did not happen.
  • gmail.compose — create drafts.

A separate credential, used only to build the demonstration dataset and never deployed, additionally requests gmail.insert and calendar.events.

These scopes grant access to your whole mailbox and calendar, not only to items Second created.

What Second does with it

Excerpts of your calendar entries and email — subject lines, senders, dates, and short quotations used as evidence — are sent to a third-party large language model provider for reasoning. Depending on configuration that provider is Google (Gemini), Groq, Cerebras, or Anthropic.

On free tiers, humans may read this. Google's terms for the unpaid Gemini API permit human reviewers to read API input and output. Other providers' free tiers carry comparable terms. If you run Second on a free tier, treat anything it reads as potentially seen by a person at that provider.

What Second stores

  • Your goals, plans, tasks and their history, in Amazon DynamoDB.
  • An audit log of every action taken, including which tool ran and why.
  • Structural observations about how you operate — for example that an 18:00 slot has been declined four times. Facts about what happened, never inferences about your character or motives.

Data is kept in the operator's own AWS account for as long as they keep it.

What Second never does

  • Send email. It writes drafts and stops.
  • Delete calendar events.
  • Move an event you do not own.
  • Sell, share, or transfer your data to anyone beyond the model provider named above and the storage described above.
  • Use your data for advertising, or to train any model. Providers' own terms govern what they do with API input; see the note above.

Google user data

Second's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can withdraw Second's access at any time at myaccount.google.com/permissions. Revoking stops all further access immediately. Data already stored is deleted by deleting the DynamoDB table in the operator's AWS account.
